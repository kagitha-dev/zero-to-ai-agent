# Ep 5 · MCP: plug-and-play tools with the Java MCP SDK

**Zero to AI Agent · Java lab · 🚧 coming soon**

Tools from Ep 4 are custom glue for one app. **MCP (Model Context Protocol)** is one standard way to offer tools, so any MCP host can use them.

## Planned

- What MCP is: host, client, server, and the tools, resources and prompts a server offers
- Building an MCP server in Java with the official [MCP Java SDK](https://github.com/modelcontextprotocol/java-sdk)
- Testing it with **MCP Inspector**
- Plugging it into **Claude Desktop** as the host

**Tools:** Java 17+, Maven, MCP Java SDK, MCP Inspector, Claude Desktop
