Why is it built this way?

    
Weights are frozen
Chatting doesn't change them. Only training does (Episode 2).

    
One model, many users
The same model answers everyone, so each request has to stand on its own.

    
It reads everything to predict
Every next token is chosen by looking at all the tokens in the window.

  

  
REMEMBERThe model doesn't remember. Your app does.
