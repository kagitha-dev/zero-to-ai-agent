EP 4 · THE THREE TOOLS OF THE ARTICLE AGENT
===========================================

Java method                          -> tool name the LLM uses
-----------------------------------------------------------------
Tools.readFile(String path)          -> read_file   { "path": "Trends.txt" }
Tools.listFiles(String folder)       -> list_files  { "folder": "articles" }
Tools.saveFile(String name, content) -> save_file   { "name": "rag.md", "content": "# RAG ..." }

All paths are inside the episode's "workspace" folder.
