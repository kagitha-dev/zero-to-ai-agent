EP 4 · POSTMAN / CURL REQUESTS
==============================

How to use
- Postman: Import > Raw text > paste ONE curl command (from "curl" to the last quote) > Import > Send.
- Terminal: paste into bash, zsh or Git Bash. (Windows cmd needs different quoting: use Postman or Git Bash.)
- Ollama must be running, with the model pulled:  ollama pull qwen3.5:4b

These requests replay the agent from the slides, one round trip at a time.
Every request (except 1) starts with the same SYSTEM message. It gives the small model clear rules:
  - "already written" means a file with that name exists in articles: skip it, don't read it
  - topics that mean the same thing get one article
  - no tool call at the end = done

Paths are relative to the lab's workspace folder (Trends.txt, articles), the same as the Java code.
If your files are somewhere else (for example D:/Trends.txt and D:/articles), change the paths in the
SYSTEM/USER messages AND in the example tool calls, and keep them consistent everywhere.

Requests 3 to 6 contain an example history. Your model may ask for slightly different steps: that's fine.
To follow your own run: copy the "message" from each reply into the next request's "messages",
then add a {"role": "tool", "tool_name": "...", "content": "..."} message with the result.
Always start a new run from request 2: a history made with older wording keeps steering the model.

With "temperature": 0 and a fixed "seed", the same request gives the same reply.
Re-sending an unchanged request won't change the answer: change the wording or the history instead.

0 · Is Ollama running? Does the model support tools?
=====================================================================

curl http://localhost:11434

ollama show qwen3.5:4b
   -> look for "tools" under Capabilities


=====================================================================
1 · The LLM alone (no tools, no system rules)
=====================================================================
Expect: an answer in text. It can't read Trends.txt or save files.

curl --location 'http://localhost:11434/api/chat' \
--header 'Content-Type: application/json' \
--data '{
  "model": "qwen3.5:4b",
  "messages": [
    {
      "role": "user",
      "content": "Read Trends.txt. For each topic, write a short article (about 150 words, in markdown) and save it as its own .md file in the articles folder. Skip topics that already have a file in the articles folder, and merge topics that mean the same thing into one article."
    }
  ],
  "think": false,
  "stream": false,
  "options": {
    "temperature": 0,
    "seed": 42
  }
}'
