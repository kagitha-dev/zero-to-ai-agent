EP 4 · POSTMAN / CURL REQUESTS
==============================

How to use
- Postman: Import > Raw text > paste ONE curl command (from "curl" to the last quote) > Import > Send.
- Terminal: paste into bash, zsh or Git Bash. (Windows cmd needs different quoting: use Postman or Git Bash.)
- Ollama must be running, with the model pulled:  ollama pull qwen3.5:4b

These requests replay the agent from the slides, one request at a time.
Requests 3 to 5 contain a history with example tool calls. Your model may ask for slightly
different steps: that's fine. To follow your own run, copy the "message" from each reply into
the next request's "messages", then add a {"role": "tool", ...} message with the result.


=====================================================================
0 · Is Ollama running? Does the model support tools?
=====================================================================

curl http://localhost:11434

ollama show qwen3.5:4b
   -> look for "tools" under Capabilities


=====================================================================
1 · The LLM alone (no tools)
=====================================================================
Expect: an answer in text. It can't read Trends.txt or save files.

curl --location 'http://localhost:11434/api/chat' \
--header 'Content-Type: application/json' \
--data '{
  "model": "qwen3.5:4b",
  "messages": [
    {
      "role": "user",
      "content": "Read Trends.txt. Write one short article (about 150 words, in markdown) for each topic, and save each article as its own .md file in the articles folder.\nConditions: skip topics I have already written, and merge similar topics into one article."
    }
  ],
  "think": false,
  "stream": false,
  "options": {
    "temperature": 0,
    "seed": 42
  }
}'
