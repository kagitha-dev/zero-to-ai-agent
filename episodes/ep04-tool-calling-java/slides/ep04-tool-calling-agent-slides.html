Before we code

  
Four rules for the loop

  

    
1 · Stop condition
No tool call = done
That's the break in our loop.

    
2 · Step limit
Cap the loop
MAX_STEPS = 10. A confused model can't loop forever.

    
3 · Errors go back
Don't crash, tell the LLM
Missing file? Send "file not found" as the result and let it decide.

    
4 · Write tools
Careful with save_file
Reading is safe. Writing can overwrite: check first, or ask.
