## All you need

- Java basics
- A laptop
- [Ollama](https://ollama.com) (free)
- **No** ML math · **no** paid API key

By Episode 7 you won't just use AI, you'll build it: an agent in Java with tools, MCP and your own data, and you'll know how every piece works underneath.
